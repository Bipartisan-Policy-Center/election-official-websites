# Election Office Website Adoption of .gov and HTTPS

This repository contains the code for the analysis described in the July 2026 Bipartisan Policy Center blog post, "[Election Offices Are Increasingly Using .gov Websites in 2026.]([https://bipartisanpolicy.org/blog/more-election-offices-are-adopting-verified-gov-websites](https://bipartisanpolicy.org/article/election-offices-are-increasingly-using-gov-websites-in-2026/))" It does not contain the original dataset itself, which is maintained by the [Center for Tech and Civic Life](https://www.techandciviclife.org/).
